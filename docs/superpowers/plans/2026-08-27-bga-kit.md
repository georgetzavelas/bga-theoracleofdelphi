# BGA Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `bga-kit/`, an untracked directory in this repository holding a copyable BGA starter skeleton plus a tiered lessons base, so the next Board Game Arena game starts on game rules instead of platform discovery.

**Architecture:** Three layers. A `skeleton/` of real files a target repo runs, where every mechanical rule is a script rather than a sentence. A `knowledge/` tier of subsystem documents with a fixed five-heading shape, read on demand. A `reference/` copy of the 2025-11 framework capture, explicitly tier-3 evidence. A five-phase mining sweep over this repository's history supplies the knowledge contents; the skeleton's contents are fixed by the spec and do not wait on it.

**Tech Stack:** PHP 8.4 (no framework, no PHPUnit), Node 22 (no framework, no jest), Bash, Markdown. Tests are plain scripts that exit non-zero on failure.

**Spec:** `docs/superpowers/specs/2026-08-27-bga-kit-design.md`

## Global Constraints

- **`bga-kit/` is gitignored in this repository** (`.gitignore:7`). Tasks that create files under it therefore **end in verification, not a commit**. Do not `git add -f`. Do not add exceptions to `.gitignore`. The only commits this plan makes are to `docs/superpowers/plans/` and `docs/superpowers/specs/`.
- **No git safety net inside `bga-kit/`.** Because nothing there is tracked, `bga-kit/tests/verify_kit.sh` is the sole regression guard. Before starting each task, snapshot with `tar czf /tmp/bga-kit-snapshot-taskN.tgz bga-kit` so a bad task can be rolled back.
- **Never add `Co-Authored-By:` or AI-attribution trailers to commit messages** on this repo (`CLAUDE.md` hard rule).
- **After any commit:** merge the feature branch into `master` with `--no-ff`, then `git push`. Standing authorization. Stop and surface merge conflicts.
- **Evidence precedence, verbatim from the spec:** (1) code at HEAD, (2) commit history with later superseding earlier, (3) `reference/framework-capture/`. Where they disagree the lower number wins and the disagreement is recorded as a lesson.
- **Writing constraint, verbatim from the spec:** No document in the kit may tell the reader not to ask something. Any claim that the platform provides a capability for free must carry the evidence for that claim and the date it was checked. A claim that cannot meet that bar is written as an open question instead of an assertion.
- **`knowledge/00-non-negotiables.md` is capped at 150 lines.** Hard constraint, not a target.
- **Placeholder game name in the skeleton is the literal string `GAMENAME`** (uppercase, no angle brackets), in both filenames and file contents. `stamp.sh` replaces it. Angle brackets break shell globbing and filenames on some filesystems.
- **PHP pinned to 8.4** in the skeleton's CI, matching what BGA runs, so a local pass on a newer PHP cannot hide a platform rejection.
- Tests are hand-rolled scripts. PHP tests use a `check(bool, string)` helper, print `N passed, M failed`, and `exit($failed === 0 ? 0 : 1)`. Node tests use `ok(cond, msg)` / `same(got, want, msg)`, print `N passed, M failed`, and `process.exit(fail === 0 ? 0 : 1)`. Match these idioms exactly; the runner reads only exit status.

```bash
#!/usr/bin/env bash
#
# The kit's acceptance suite. Run it after every task.
#
# Checks are discovered by glob, not listed here, so a new
# tests/check_*.sh is picked up with no edit to this file. That is the same
# mechanism that kept the source project's tests/run_all.sh correct for ten
# months while a prose rule about cache-bust markers went stale twice.
#
# No `set -e`: a failing check must not abort the run. The point is to report
# every failure in one pass.
#
# Usage:  bash bga-kit/tests/verify_kit.sh
set -uo pipefail
shopt -s nullglob

KIT_ROOT="$(cd "$(dirname "$0")/.." && pwd)"
export KIT_ROOT

pass=0; fail=0; failed=()

for f in "$KIT_ROOT"/tests/check_*.sh; do
    printf '  %-40s ' "$(basename "$f")"
    if out=$(bash "$f" 2>&1); then
        printf 'ok\n'; pass=$((pass + 1))
    else
        printf 'FAIL\n'; fail=$((fail + 1)); failed+=("$f")
        printf '%s\n' "$out" | sed 's/^/      /'
    fi
done

echo
if [ "$fail" -eq 0 ]; then
    echo "$pass checks passed."
    exit 0
fi
echo "$fail of $((pass + fail)) checks FAILED:"
for f in "${failed[@]}"; do echo "  $(basename "$f")"; done
exit 1
```

```bash
    printf '%s\n' "$out" | sed 's/^/    /'

cat > "$tmp/tests/test_zz_probe.php" <<'PROBE'
```

Create `bga-kit/skeleton/tests/run_all.sh` and `chmod +x` it:

```bash
#!/usr/bin/env bash
#
# Run every test in tests/ and exit non-zero if any of them fails.
#
# This is the one entry point: run it before a commit, and CI runs the same
# script, so the two can never drift. Tests are discovered by glob, not listed
# here, so a new tests/test_*.php or tests/test_*_js.js is picked up with no
# edit to this file. Support scripts do not carry the test_ prefix and are
# skipped.
#
# Every test file already exits non-zero on failure, so nothing here parses
# output -- a file's exit status is the verdict.
#
# Usage:  bash tests/run_all.sh
#         PHP=/path/to/php bash tests/run_all.sh
#
# Note: no `set -e`. A failing test must not abort the run; the point is to
# report every failure in one pass.
set -uo pipefail
shopt -s nullglob

cd "$(dirname "$0")/.."

# --- interpreters -----------------------------------------------------------
# Homebrew's php is not on a non-login shell's PATH on macOS, and silently
# skipping half the suite is the exact failure this script exists to prevent,
# so an interpreter that cannot be found is a hard error.
find_bin() {
    local override="$1"; shift
    if [ -n "$override" ]; then
        command -v "$override" >/dev/null 2>&1 && { printf '%s' "$override"; return 0; }
        return 1
    fi
    local cand
    for cand in "$@"; do
        command -v "$cand" >/dev/null 2>&1 && { printf '%s' "$cand"; return 0; }
    done
    return 1
}

PHP_BIN=$(find_bin "${PHP:-}" php /opt/homebrew/bin/php /usr/local/bin/php /usr/bin/php) || {
    echo "error: no php found. Install it, put it on PATH, or set PHP=/path/to/php." >&2
    exit 2
}
NODE_BIN=$(find_bin "${NODE:-}" node /opt/homebrew/bin/node /usr/local/bin/node) || {
    echo "error: no node found. Install it, put it on PATH, or set NODE=/path/to/node." >&2
    exit 2
}

# Cross-language parity tests shell out to php themselves; hand them the same
# binary this run resolved, so both halves of the suite test one PHP.
export PHP="$PHP_BIN"

echo "php:  $PHP_BIN ($("$PHP_BIN" -r 'echo PHP_VERSION;'))"
echo "node: $NODE_BIN ($("$NODE_BIN" --version))"
echo

# --- run --------------------------------------------------------------------
pass=0
fail=0
failed=()

run_test() {
    local bin="$1" file="$2" out
    printf '  %-42s ' "$(basename "$file")"
    if out=$("$bin" "$file" 2>&1); then
        printf 'ok\n'
        pass=$((pass + 1))
    else
        printf 'FAIL\n'
        fail=$((fail + 1))
        failed+=("$file")
        printf '%s\n' "$out" | sed 's/^/      /'
    fi
}

for f in tests/test_*.php; do run_test "$PHP_BIN" "$f"; done
for f in tests/test_*_js.js; do run_test "$NODE_BIN" "$f"; done

# --- verdict ----------------------------------------------------------------
echo
if [ "$fail" -eq 0 ]; then
    echo "$pass test files passed."
    exit 0
fi

echo "$fail of $((pass + fail)) test files FAILED:"
for f in "${failed[@]}"; do echo "  $f"; done
exit 1
```

```php
<?php
/**
 * The PHP test idiom for this project. Copy this shape.
 *
 * There is no PHPUnit here and that is deliberate: BGA runs your code on its
 * own PHP with no composer install, so a test that needs a package cannot run
 * against what ships. A script that exits non-zero is the whole contract --
 * tests/run_all.sh reads only the exit status.
 *
 * Run: php tests/test_example.php
 */
declare(strict_types=1);

$passed = 0; $failed = 0;
function check(bool $c, string $m): void {
    global $passed, $failed;
    if ($c) { $passed++; } else { $failed++; echo "FAIL: $m\n"; }
}

// A worked assertion, so the file is a demonstration and not a stub.
check(PHP_VERSION_ID >= 80400, 'PHP is 8.4 or newer, matching what BGA runs');
check(json_encode(['a' => 1]) === '{"a":1}', 'json_encode behaves as expected');

echo "\n$passed passed, $failed failed\n";
exit($failed === 0 ? 0 : 1);
```

Create `bga-kit/skeleton/tests/test_example_js.js`:

```javascript
/**
 * The Node test idiom for this project. Copy this shape.
 *
 * Client code ships as Dojo AMD modules that a browser loads, but they are
 * testable under plain node by running the file in a vm sandbox with a stub
 * `define` and a stub `declare`. loadModule below is that harness; it is the
 * reason client-side geometry and rendering logic can be tested at all
 * without a browser or a BGA Studio table.
 *
 * Run: node tests/test_example_js.js
 */
'use strict';
const fs = require('fs');
const path = require('path');
const vm = require('vm');

let pass = 0, fail = 0;
function ok(cond, msg) {
    if (cond) { pass++; } else { console.log('  FAIL: ' + msg); fail++; }
}
function same(got, want, msg) {
    const g = JSON.stringify(got), w = JSON.stringify(want);
    ok(g === w, g === w ? msg : msg + '  (got ' + g + ' want ' + w + ')');
}

/**
 * Load a Dojo AMD module without a browser. Returns the factory's return value
 * as `Class` and the declare() spec object as `spec`, so a test can call
 * methods directly off `spec` with no instance, or construct via `Class`.
 */
function loadModule(relPath) {
    const sandbox = {
        console, Math, Map, Set, JSON, captured: null, spec: null,
        define(_deps, factory) {
            // Arity-agnostic on purpose. Dojo's declare() is called as
            // declare(spec), declare(superclass, spec), or
            // declare(className, superclass, spec); the spec is always LAST.
            // A stub that destructured exactly two parameters silently bound
            // spec to `null` for the three-argument form, which is the form
            // the main game file and any named class use, and the failure
            // surfaced only later as "cannot read properties of null".
            const stubDeclare = (...args) => {
                const spec = args[args.length - 1];
                sandbox.spec = spec;
                return function (...ctorArgs) {
                    Object.assign(this, spec);
                    if (typeof spec.constructor === 'function') {
                        spec.constructor.apply(this, ctorArgs);
                    }
                };
            };
            sandbox.captured = factory({}, stubDeclare);
        },
    };
    vm.createContext(sandbox);
    vm.runInContext(fs.readFileSync(path.join(__dirname, '..', relPath), 'utf8'), sandbox);
    return { Class: sandbox.captured, spec: sandbox.spec };
}
module.exports = { loadModule };

// This file is BOTH a test and the loader library other tests import, so its
// own assertions must not run on require. Without this guard the bare
// process.exit() below fires at import time and kills the requiring test
// before it reaches a single assertion of its own -- exiting 0, so the
// suite reports a pass for a test that never ran.
if (require.main === module) {
    // A worked assertion, so the file is a demonstration and not a stub.
    same([1, 2].map(n => n * 2), [2, 4], 'the harness runs and same() reports correctly');
    ok(typeof loadModule === 'function', 'loadModule is available for module tests');

    console.log(pass + ' passed, ' + fail + ' failed');
    process.exit(fail === 0 ? 0 : 1);
}
```

```php
 * Game.php — the game's server-side entry point.
 *

 * methods, and because every feature had to touch it, it became the single
 * worst merge contention point in the codebase. Rules logic belongs in a
 * focused class under modules/php/; turn flow belongs in a state class under
 * modules/php/States/. `bash scripts/check-conventions.sh` caps this file.
 */
declare(strict_types=1);

namespace Bga\Games\GAMENAME;

use Bga\Games\GAMENAME\States\GameSetup;

require_once(__DIR__ . '/UndoState.php');

class Game extends \Bga\GameFramework\Table
{
    public function __construct()
    {
        parent::__construct();

        // Typed globals. The previous generation stored integers only, via
        // getGameStateValue/setGameStateValue; this replaces it and accepts
        // any JSON-serialisable type.
        // (checked 2026-08-27, https://en.doc.boardgamearena.com/Main_game_logic:_Game.php#Use_globals)
        $this->globals->initialize([
            'example_counter' => 0,
        ]);
    }

    /**
     * Everything the client needs to render, scoped to ONE player.
     *
     * The $playerId argument is not decoration. Broadcasting a single
     * getAllDatas() built for one player to every client leaks that player's
     * private information to their opponents and overwrites each opponent's
     * own view. That bug shipped in the source project and had to be fixed by
     * replacing one notify->all with a per-player loop.
     * See bga-kit/knowledge/15-private-state-and-privacy.md.
     */
    protected function getAllDatas(?int $playerId = null): array
    {
        $playerId ??= (int) $this->getCurrentPlayerId();

        return [
            'players' => $this->getCollectionFromDb(
                "SELECT player_id, player_score, player_name, player_color
                 FROM player"
            ),
            // Add only what this player may see. Anything private must be
            // filtered by $playerId here, not hidden on the client.
        ];
    }

    protected function getGameProgression(): int
    {
        return 0;
    }

    protected function setupNewGame($players, $options = [])
    {
        // The framework does not create player rows for you. Insert them here.
        // player_canal and player_avatar are no longer populated by the
        // framework (BGA 2026 deprecations), so they are deliberately omitted.
        $default_colors = $this->getGameinfos()['player_colors'];
        $values = [];
        foreach ($players as $playerId => $player) {
            $values[] = vsprintf("('%s', '%s', '%s')", [
                $playerId,
                array_shift($default_colors),
                addslashes($player['player_name']),
            ]);
        }
        static::DbQuery(sprintf(
            "INSERT INTO player (player_id, player_color, player_name) VALUES %s",
            implode(',', $values)
        ));

        $this->ensurePlayerColumns();
        $this->activeNextPlayer();
    }

    /**
     * Add game-owned columns to the framework's `player` table.
     *
     * Done here rather than in dbmodel.sql because BGA replays that file and
     * a plain ALTER would fail with "Duplicate column".
     *
     * OWNED_PLAYER_COLUMNS is the single source of truth for two consumers:
     * this method, and the undo engine's restore. Undo must restore only
     * columns the game owns; restoring framework columns (player_beginner,
     * reflexion time, zombie/eliminated, name, colour) both clobbers state the
     * game has no business reverting and, in the source project, overflowed a
     * narrow column and broke undo outright.
     * See bga-kit/knowledge/12-undo.md.
     */
    public const OWNED_PLAYER_COLUMNS = [
        // 'example_resource' => "INT NOT NULL DEFAULT 0",
    ];

    private function ensurePlayerColumns(): void
    {
        foreach (self::OWNED_PLAYER_COLUMNS as $col => $ddl) {
            $exists = $this->getUniqueValueFromDB(
                "SELECT COUNT(*) FROM information_schema.COLUMNS
                 WHERE TABLE_SCHEMA = DATABASE()
                   AND TABLE_NAME = 'player'
                   AND COLUMN_NAME = '" . $col . "'"
            );
            if ((int) $exists === 0) {
                $this->DbQuery("ALTER TABLE player ADD `$col` $ddl");
            }
        }
    }

    /**
     * Level 1 zombie handling is mandatory for release: a player who quits
     * must not stall the table for everyone else.
     *
     * Delegate to the framework rather than hand-rolling transitions. For an
     * active-player state, runStateClassZombie asks the state class itself what
     * a zombie should do, which keeps the answer next to the state's own rules.
     */
    public function zombieTurn(array $state, int $active_player): void
    {
        $type = $state['type'] ?? '';

        if ($type === 'activeplayer') {
            $this->gamestate->runStateClassZombie(
                $this->gamestate->getCurrentState($active_player),
                $active_player
            );
            return;
        }

        if ($type === 'multipleactiveplayer') {
            $this->gamestate->setPlayerNonMultiactive($active_player, '');
            return;
        }

        throw new \BgaVisibleSystemException(
            "Zombie mode not supported at state: " . ($state['name'] ?? '?')
        );
    }
}
```

```php
 * The BGA framework classes do not exist outside Studio, so these state files
 * cannot be autoloaded here. Reading them as text is deliberate, and it still
 * catches the mistakes that actually happen: a duplicate state id, a missing
 * PossibleAction attribute, an action method that does not start with `act`.

function check(bool $c, string $m): void {

    if ($c) { $passed++; } else { $failed++; echo "FAIL: $m\n"; }

// Strict on purpose. An earlier draft tolerated a missing directory so the
// test could run inside a tests-only copy, which made it pass having asserted
// nothing -- the worst outcome for a test. The harness check now copies the
// whole skeleton instead, so this can demand the real thing.
$dir = __DIR__ . '/../modules/php/States';

check(count($files) > 0, 'there is at least one state class');

$ids = [];
foreach ($files as $f) {
    $src  = (string) file_get_contents($f);
    $base = basename($f, '.php');

    // Traits are mixins, not states; they carry no id.
    if (preg_match('/^\s*trait\s+/m', $src)) { continue; }

    check((bool) preg_match('/^\s*class\s+' . preg_quote($base, '/') . '\b/m', $src),
        "$base declares a class matching its filename");

    if (preg_match('/id:\s*(\d+)/', $src, $m)) {
        $id = (int) $m[1];
        check(!isset($ids[$id]), "state id $id is unique (" . $base . ")");
        $ids[$id] = $base;
    } else {
        check(false, "$base passes a numeric id to parent::__construct");
    }

    // Autowired actions must be act-prefixed, or real-time clients call a
    // name the server does not answer to.
    if (preg_match_all('/#\[PossibleAction\]\s*(?:public\s+)?function\s+(\w+)/', $src, $mm)) {
        foreach ($mm[1] as $method) {
            check(str_starts_with($method, 'act'),
                "$base::$method is act-prefixed");
        }
    }
}

echo "\n$passed passed, $failed failed\n";
exit($failed === 0 ? 0 : 1);
```

```bash
#!/usr/bin/env bash
#
# Bump the client cache-bust version.
#
# This exists because the equivalent written instruction in the source project
# was wrong in two ways at once: it named a file that had been renamed months
# earlier, and it said six markers when there were eleven, one of which sat
# inside the comment reminding you to update them. A script cannot drift from
# the file it edits.
#
# Usage:  bash scripts/bump-js-version.sh          # max(markers) + 1
#         bash scripts/bump-js-version.sh v452     # set explicitly
set -euo pipefail

cd "$(dirname "$0")/.."

shopt -s nullglob
files=(*.js modules/js/*.js modules/**/*.js)
[ ${#files[@]} -gt 0 ] || { echo "error: no .js files found." >&2; exit 2; }

# Collect every marker in either form: "vNNN" or ?vNNN.
current=$(grep -hoE '"v[0-9]{3,}"|\?v[0-9]{3,}' "${files[@]}" 2>/dev/null \
          | grep -oE '[0-9]{3,}' | sort -n | tail -1 || true)

if [ -n "${1:-}" ]; then
    new="${1#v}"
    [[ "$new" =~ ^[0-9]{3,}$ ]] || {
        echo "error: version must look like v452 (3+ digits)." >&2; exit 2; }
else
    [ -n "$current" ] || { echo "error: no version marker found to bump." >&2; exit 2; }
    new=$(printf '%0*d' "${#current}" $((10#$current + 1)))
fi

echo "bumping v${current:-none} -> v$new"

changed=0
for f in "${files[@]}"; do
    before=$(cat "$f")
    # Both forms, in one pass, so neither can be left behind.
    after=$(printf '%s' "$before" \
```

```bash
#
# Five drift checks. Install as a pre-commit hook:
#
#     ln -sf ../../scripts/check-conventions.sh .git/hooks/pre-commit
#
# Each check exists because prose could not hold the rule. Anything here that a
# script cannot check does not belong in the skeleton; it belongs in
# bga-kit/knowledge/00-non-negotiables.md.
#
# Usage:  bash scripts/check-conventions.sh

cd "$(dirname "$0")/.."
shopt -s nullglob

fail=0
note() { echo "  $*"; fail=1; }

shell=$(ls -1 *.js 2>/dev/null | head -1)
css=$(ls -1 *.css 2>/dev/null | head -1)

# --- 1. every cache-bust marker agrees with the single version constant -----
if [ -n "$shell" ]; then
    want=$(grep -oE '^var JS_VERSION = "v[0-9]{3,}";$' "$shell" \
           | grep -oE '[0-9]{3,}' || true)
    if [ -z "$want" ]; then
        note "no canonical 'var JS_VERSION = \"vNNN\";' line in $shell"
    else
        while IFS= read -r m; do
            [ "$m" = "$want" ] || note "cache-bust marker v$m disagrees with JS_VERSION v$want (run scripts/bump-js-version.sh)"
        done < <(grep -hoE '"v[0-9]{3,}"|\?v[0-9]{3,}' *.js modules/js/*.js 2>/dev/null \
                 | grep -oE '[0-9]{3,}' | sort -u)
    fi
fi

# --- 2. every module under modules/js/ is registered in GAME_MODULES --------
if [ -n "$shell" ]; then
    reg=$(sed -n '/var GAME_MODULES = \[/,/\];/p' "$shell" | grep -oE '"[A-Za-z0-9_]+"' | tr -d '"')
    for f in modules/js/*.js; do
        b=$(basename "$f" .js)
        grep -qxF "$b" <<<"$reg" || note "module $b is not registered in GAME_MODULES ($shell)"
    done
    for b in $reg; do
        [ -f "modules/js/$b.js" ] || note "GAME_MODULES lists $b but modules/js/$b.js does not exist"
    done
fi

# --- 3. CSS sections alphabetical, selectors name their section -------------
if [ -n "$css" ]; then
    slugs=$(grep -oE '^/\* ===== component: [a-z0-9-]+ ===== \*/$' "$css" \
            | sed -E 's|.*component: ([a-z0-9-]+) .*|\1|')
    if [ -n "$slugs" ]; then
        [ "$slugs" = "$(printf '%s\n' "$slugs" | LC_ALL=C sort)" ] \
            || note "CSS sections are not in alphabetical order in $css"
    fi
    awk -v css="$css" '
        /^\/\* ===== component: [a-z0-9-]+ ===== \*\/$/ {
            match($0, /component: [a-z0-9-]+/);
            slug = substr($0, RSTART + 11, RLENGTH - 11); next
        }
        /^[^[:space:]#\/@].*\{[[:space:]]*$/ {
            if (slug == "") { print "  CSS rule before the first section header: " css ":" NR; bad = 1; next }
            if (index($0, slug) == 0) { print "  CSS rule does not name section \"" slug "\": " css ":" NR; bad = 1 }
        }
        END { exit bad ? 1 : 0 }
    ' "$css" || fail=1
fi

# --- 4. no knowledge document suppresses a question ------------------------
# The most expensive failure in the source project's inputs was a section
# titled "Don't Ask About These" declaring undo and mobile responsiveness free.
# Both became its two largest sinks.
if [ -d bga-kit/knowledge ]; then

        note "question-suppressing phrasing: $hit"
    done < <(grep -rinE "do not ask|don'?t ask|no need to implement" bga-kit/knowledge/ || true)
fi

# --- 5. .gitignore must not untrack the kit --------------------------------
if [ -f .gitignore ]; then

        grep -qxF "$pat" .gitignore \
            && note ".gitignore ignores $pat; gitignored files do not reach a worktree, so parallel agents would not see the kit"
    done
fi

if [ "$fail" -eq 0 ]; then
    echo "conventions ok"
    exit 0
fi
echo
echo "check-conventions.sh found problems (see above)."
exit 1
```

```php
<?php
/**
 * Pure serialization contract for the undo buffer.
 *
 * No DB access and no framework dependency, so it is unit-testable with the
 * plain-script harness. Game reads and writes rows; this class only turns the
 * resulting array into JSON and back.
 *
 * WHY THIS EXISTS FROM DAY ONE
 *
 * In-turn undo is the game's job, not the platform's. The source project's own
 * framework notes said otherwise, deferred undo 8.3 months, and then spent 34
 * of its final 231 commits on it, 16 of them bug fixes. Every trap below is
 * one of those fixes. Building this first makes every later feature
 * snapshot-aware for free.
 */
declare(strict_types=1);

namespace Bga\Games\GAMENAME;

final class UndoState
{
    /**
     * Game-content tables captured by the snapshot.
     *
     * Three exclusions, each deliberate:
     *  - tables that never change after setup, because capturing them wastes
     *    payload and restoring them can only do harm;
     *  - `player` and `stats`, handled by column UPDATE rather than
     *    delete-and-reinsert, so the framework's own rows survive;
     *  - `undo_snapshot` itself, which must never be captured.
     */
    public const SNAPSHOT_TABLES = [
        // 'example_piece',
    ];

    /**
     * Turn-scoped globals captured by the snapshot.
     *
     * Only keys a single action can mutate. Cross-turn and setup globals are
     * stable within a turn, so omitting them is safe and keeps the payload
     * small. Add a key here whenever you add a turn-scratch global, or undo
     * will restore the board and leave the scratch value behind.
     */
    public const GLOBAL_KEYS = [
        // 'example_counter',
    ];

    /**
     * Player-table columns the snapshot may write back.
     *
     * MUST be Game::OWNED_PLAYER_COLUMNS plus 'player_score'. Restoring every
     * captured player column instead of an allowlist was a real failure: it
     * clobbered framework state the game has no business reverting (reflexion
     * time, zombie and eliminated flags, name, colour) and it crashed outright
     * with "Data too long for column 'player_beginner'", because that
     * framework column held non-UTF-8 bytes that widened on capture.
     */
    public static function restorablePlayerColumns(): array
    {
        return array_merge(array_keys(Game::OWNED_PLAYER_COLUMNS), ['player_score']);
    }

    public static function encode(array $state): string
    {
        // JSON_INVALID_UTF8_SUBSTITUTE: one row holding malformed UTF-8 would
        // otherwise make json_encode return false, which a `: string` return
        // type turns into a TypeError. In the source project that was swallowed
        // silently, leaving undo dead for the whole game. Substituting bad
        // bytes with U+FFFD keeps a disposable snapshot usable instead of
        // failing the entire buffer closed.
        $json = json_encode([
            'tables'  => $state['tables']  ?? [],
            'globals' => $state['globals'] ?? [],
            // Scores are captured and restored through the framework's counter
            // API, keyed by player id, never as a player-table column by name.
            'scores'  => $state['scores']  ?? [],
        ], JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_INVALID_UTF8_SUBSTITUTE);

        // With bad UTF-8 already substituted, false here means a cause
        // substitution cannot rescue (Inf/NaN, max depth). Surface it with a
        // real message rather than a bare TypeError.
        if ($json === false) {
            throw new \RuntimeException(
                'UndoState::encode failed: ' . json_last_error_msg()
            );
        }
        return $json;
    }

    /** @return array{tables: array, globals: array, scores: array} */
    public static function decode(string $json): array
    {
        $decoded = json_decode($json, true);
        if (!is_array($decoded)) {
            return ['tables' => [], 'globals' => [], 'scores' => []];
        }
        return [
            'tables'  => $decoded['tables']  ?? [],
            'globals' => $decoded['globals'] ?? [],
            'scores'  => $decoded['scores']  ?? [],
        ];
    }
}
```

Create `bga-kit/skeleton/modules/php/UndoEngine.php`. Method names and signatures are taken from the source project's working implementation:

```php
<?php
/**
 * The undo engine: the half of undo that touches the database.
 *
 * Separate from UndoState (pure serialization, no DB, unit-testable) and from
 * Game (capped at 250 lines, and every feature already has to touch it).
 *
 * Single-level, in-turn undo. One snapshot row, overwritten. Taken BEFORE an
 * action mutates anything, so there is something to return to.
 */
declare(strict_types=1);

namespace Bga\Games\GAMENAME;

final class UndoEngine
{
    public function __construct(private Game $game) {}

    /** Read the current game state into a plain array. No side effects. */
    public function captureUndoState(): array
    {
        $tables = [];
        foreach (UndoState::SNAPSHOT_TABLES as $t) {
            $tables[$t] = $this->game->getObjectListFromDB("SELECT * FROM `$t`");
        }

        $globals = [];
        foreach (UndoState::GLOBAL_KEYS as $k) {
            $globals[$k] = $this->game->globals->get($k);
        }

        // Game-owned player columns only. Never capture-and-restore framework
        // columns: doing so clobbers reflexion time, zombie and eliminated
        // flags, name and colour, and one of them held non-UTF-8 bytes that
        // widened on capture and overflowed its column, killing undo outright.
        $cols = UndoState::restorablePlayerColumns();
        $players = $cols
            ? $this->game->getObjectListFromDB(
                "SELECT player_id, " . implode(', ', array_map(
                    fn($c) => "`$c`", $cols)) . " FROM player")
            : [];
        $tables['player'] = $players;

        // Scores go through the counter API, keyed by player id, never as a
        // player-table column looked up by name.
        $scores = [];
        foreach ($this->game->getObjectListFromDB("SELECT player_id FROM player") as $row) {
            $pid = (int) $row['player_id'];
            $scores[$pid] = [
                'primary' => (int) $this->game->getUniqueValueFromDB(
                    "SELECT player_score FROM player WHERE player_id = $pid"),
            ];
        }

        return ['tables' => $tables, 'globals' => $globals, 'scores' => $scores];
    }

    /** Write a captured state back. Inverse of captureUndoState. */
    public function restoreUndoState(array $state): void
    {
        foreach (UndoState::SNAPSHOT_TABLES as $t) {
            $rows = $state['tables'][$t] ?? null;
            if ($rows === null) { continue; }          // absent, not empty
            $this->game->DbQuery("DELETE FROM `$t`");
            foreach ($rows as $row) {
                $cols = implode(', ', array_map(fn($c) => "`$c`", array_keys($row)));
                $vals = implode(', ', array_map(
                    fn($v) => $v === null ? 'NULL' : "'" . addslashes((string) $v) . "'",
                    $row));
                $this->game->DbQuery("INSERT INTO `$t` ($cols) VALUES ($vals)");
            }
        }

        // player: UPDATE an allowlist of columns, never delete and reinsert.
        $allowed = UndoState::restorablePlayerColumns();
        foreach ($state['tables']['player'] ?? [] as $row) {
            $pid = (int) ($row['player_id'] ?? 0);
            if ($pid === 0) { continue; }
            $sets = [];
            foreach ($row as $col => $v) {
                if ($col === 'player_id' || !in_array($col, $allowed, true)) { continue; }
                $sets[] = "`$col` = " .
                    ($v === null ? 'NULL' : "'" . addslashes((string) $v) . "'");
            }
            if ($sets) {
                $this->game->DbQuery(
                    "UPDATE player SET " . implode(', ', $sets) .
                    " WHERE player_id = $pid");
            }
        }

        foreach ($state['globals'] ?? [] as $k => $v) {
            if (in_array($k, UndoState::GLOBAL_KEYS, true)) {
                $this->game->globals->set($k, $v);
            }
        }

        foreach ($state['scores'] ?? [] as $pid => $sc) {
            $this->game->DbQuery(sprintf(
                "UPDATE player SET player_score = %d WHERE player_id = %d",
                (int) ($sc['primary'] ?? 0), (int) $pid));
        }
    }

    /**
     * Take the snapshot. Call this at the TOP of every action that mutates
     * state, before the mutation, with a short label naming what is being
     * undone. The label is shown on the Undo button.
     */
    public function undoCheckpoint(string $label): void
    {
        $payload = UndoState::encode($this->captureUndoState());
        $this->game->DbQuery(sprintf(
            "INSERT INTO undo_snapshot (id, payload, available, action_label)
             VALUES (1, '%s', 1, '%s')
             ON DUPLICATE KEY UPDATE payload = VALUES(payload),
                                     available = 1,
                                     action_label = VALUES(action_label)",
            addslashes($payload), addslashes(substr($label, 0, 64))));
    }

    public function undoAvailable(): bool
    {
        return (int) $this->game->getUniqueValueFromDB(
            "SELECT available FROM undo_snapshot WHERE id = 1") === 1;
    }

    /** Drop the checkpoint without restoring, e.g. when an action is cancelled. */
    public function clearUndoCheckpoint(): void
    {
        $this->game->DbQuery("UPDATE undo_snapshot SET available = 0 WHERE id = 1");
    }

    /**
     * Restore the snapshot and tell every client to repaint.
     *
     * PER-PLAYER, not broadcast. Sending one getAllDatas() to every client
     * leaks the acting player's private information to their opponents and
     * overwrites each opponent's own view. That shipped as a bug in the source
     * project and had to be replaced with exactly this loop.
     *
     * @return string the state class to route back to
     */
    public function performUndo(): string
    {
        $payload = (string) $this->game->getUniqueValueFromDB(
            "SELECT payload FROM undo_snapshot WHERE id = 1");
        $this->restoreUndoState(UndoState::decode($payload));
        $this->clearUndoCheckpoint();

        foreach ($this->game->getObjectListFromDB("SELECT player_id FROM player") as $row) {
            $pid = (int) $row['player_id'];
            $this->game->notify->player($pid, 'undoRestore', '', [
                'player_id' => $pid,
                'gamedatas' => $this->game->getAllDatasFor($pid),
            ]);
        }

        return States\PlayerTurn::class;
    }
}
```
